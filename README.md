# میدان ریاضی — MATH ARENA

یک بازی موبایل رقابتی ریاضی برای پایهٔ دهم، ساخته‌شده روی **کتاب ریاضی (۱) پایهٔ دهم (کد ۱۱۰۲۱۱)** — با موتور دوئل شش‌مرحله‌ای، بازی آنلاین واقعی، حالت‌های آفلاین، موتور یادگیری تطبیقی و دستیار ریاضی.

**نسخهٔ ۲.۰.۰** — ارتقای بزرگ «هوشمند، مبتنی بر کتاب، رقابتی»:
- **موتور سؤال هوشمند**: ۸ خانوادهٔ سؤال ( مفهومی، وارونه، خطایابِ گام غلط، چندمرحله‌ای، کاربردی، قضاوت همیشه/گاهی/هرگز، چالشی، مستقیم ) با تنوع ساختاری، اثرانگشت ضدتکرار، ۴ سطح سختی مبتنی بر عمق استدلال و بازخورد اختصاصی برای هر گزینهٔ غلط.
- **اتصال به کتاب درسی**: هر سؤال نشان مرجع ( فصل · درس · صفحهٔ چاپی ) دارد و با «مشاهده در کتاب» صفحهٔ واقعی PDF همان مبحث باز می‌شود — بدون از دست دادن پیشرفت مسابقه.
- **تختهٔ خط‌کشی**: بوم رسم تمام‌صفحه با ۳ رنگ، ۳ ضخامت، پاک‌کن، شبکه، واگرد/بازانجام و ماندگاری خط‌ها در همان سؤال.
- **رابط نیوی رقابتی**: طراحی مجدد کامل با پالت سرمه‌ای عمیق، پنل‌های مستطیلی و خطوط ظریف — جایگزین سبک کارتونی.
- **تحلیل آموزشی**: دقت به تفکیک مفهوم/سطح سختی/خانوادهٔ سؤال، الگوی اشتباه‌های تکرارشونده و توصیهٔ تمرین مبتنی بر نقطهٔ ضعف ( بدون بازآزمون مفاهیم مسلط‌شده ).
- همهٔ امکانات v1 ( حالت‌ها، آفلاین، چندنفرهٔ سرورمختار، پیشرفت کاربران ) حفظ و با مهاجرت امن داده ارتقا یافت.

A competitive mathematics game for Grade-10 students, built from the supplied
Iranian Grade-10 Mathematics textbook (Riazi 1, code 110211). Six-stage
duels, real-time online multiplayer, a full offline engine, an adaptive
learning loop and a math tutor — packaged as an installable Android APK.

**v2.0.0 — the intelligent, textbook-anchored, competitive upgrade:**
8 question families with structural variety + anti-duplication fingerprints
+ 4 reasoning-based difficulty tiers + per-distractor mistake feedback;
persistent textbook traceability with an in-app book viewer that returns to
the game without losing progress; a full drawing whiteboard (colors,
widths, eraser, grid, undo/redo, per-question persistence); a complete
deep-navy competitive redesign; and per-concept / per-tier / per-family
educational analytics. All v1 features and data preserved via safe
migration.

## سریع‌ترین مسیر / Quick start

### بازی (اندروید)
1. `release/MathArena-v2.0.0.apk` را روی گوشی اندرویدی (اندروید ۷ به بالا) منتقل و نصب کنید.
2. بازی کاملاً آفلاین کار می‌کند: ساخت پروفایل، مسیر تمرین، دوئل با ربات، همهٔ حالت‌ها، «بهتر شو در ۱۵»، دفتر اشتباهات و دستیار.
3. برای بازی آنلاین: در «تنظیمات» آدرس سرور را وارد کنید (بخش زیر).

### سرور بازی (آنلاین)
```bash
cd server
npm install
cp .env.example .env         # MA_SECRET را عوض کنید
npm start                    # http://0.0.0.0:8080
```
یا با Docker:
```bash
docker compose up --build    # server + redis
```
سپس در بازی: تنظیمات ← «اتصال به سرور بازی» ← `http://<آدرس-سرور>:8080` ← «تست اتصال».

برای جزئیات استقرار روی اینترنت: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)

## محتوا: از کتاب تا بانک سؤال

خط تولید محتوا (Python) کل کتاب را پردازش می‌کند:

| مرحله | خروجی |
| --- | --- |
| استخراج کامل PDF (۱۷۶ صفحه، بدون نیاز به OCR) | `content/book_pages.json` |
| ساختار برنامهٔ درسی (۷ فصل، ۲۳ درس، ۳۸ مهارت) | `content/curriculum.json` |
| تولید سؤال پارامتری + اعتبارسنجی مستقل | `content/question_bank.json` (**۹۷۴ سؤال تاییدشده**) |
| گزارش اعتبارسنجی | `content/question_validation_report.json` |
| گزارش پوشش کتاب | `content/book_coverage_report.json` |

**صحت ریاضی غیرقابل مذاکره است:** هر سؤال پیش از ورود به بانک، با روشی مستقل از مولد (تکرار به‌جای فرمول بسته، شمارش جامع با itertools، ارزیابی نقطه‌ای، بررسی ریشه‌ها با جای‌گذاری، ماژول statistics و…) دوباره حل و بررسی می‌شود؛ سؤالی که پاسخش تأیید نشود هرگز وارد مسابقه نمی‌شود.

اجرای دوبارهٔ خط تولید:
```bash
python3 content/pipeline/extract_book.py   # needs the textbook PDF (MA_PDF env or default path)
python3 content/pipeline/curriculum.py
python3 content/pipeline/build_bank.py     # regenerates + validates deterministically
```

## معماری

```
اندروید (APK)
  └── WebView shell (Java)  ←  assets: بازی کامل HTML5 (Vanilla JS, RTL, فونت وزیرمتن)
        │  file:///android_asset/index.html
        │  REST + Socket.IO (آدرس سرور قابل تنظیم در بازی)
        ▼
سرور Node.js (Express + Socket.IO)
  ├── احراز هویت (توکن HMAC) و پروفایل‌ها
  ├── لابی زنده، اتاق‌ها با کد، آماده‌سازی
  ├── موتور دوئل سمت-سرور (شش مرحله × ۳ سؤال، تایمرها، امتیاز، کمک‌ها)
  ├── رده‌بندی Elo + ضد-فارم + ردهٔ فصلی
  ├── دوستان (کد دوستی، درخواست، چالش)، جام‌ها (امتیازی + حذفی)
  ├── چالش روزانه + زمان‌بند node-cron (هر دقیقه/روز/هفته/فصل)
  ├── دستیار AI (لایهٔ پروایدر-مستقل + حالت قطعی مبتنی بر کتاب)
  └── ذخیره‌سازی JSON (تک‌نود) — اسکیمای Prisma/Postgres برای استقرار بزرگ
```

- **آنلاین واقعی است:** سرور صاحب حقیقت است؛ پاسخ درست هرگز پیش از قفل شدن سؤال برای هر دو بازیکن ارسال نمی‌شود، امتیاز و رده فقط سمت سرور محاسبه می‌شود و قطع‌وصل با پنجرهٔ اتصال مجدد (۴۵ ثانیه) مدیریت می‌شود.
- **آفلاین هم شهروند درجه‌یک است:** تمام حالت‌ها بدون اینترنت؛ نتایج آفلاین روی ردهٔ آنلاین اثر نمی‌گذارند و بعد از اتصال، به‌صورت idempotent همگام می‌شوند.

## حالت‌های بازی

| حالت | توضیح |
| --- | --- |
| **دوئل کلاسیک (آرنا)** | ۶ مرحله × ۳ سؤال = ۱۸ سؤال؛ انتخاب موضوع متناوب؛ آنلاین/بات/دو نفره روی یک گوشی |
| برق‌آسا (Blitz) | ۹۰ ثانیه، کمبو، پاداش سرعت |
| بقا (Survival) | ۳ جان، سختی فزاینده (+ نسخهٔ تمرینی بدون جان) |
| ماراتن | ۳۰ سؤال از همهٔ فصل‌ها با سختی فزاینده |
| دقت (Precision) | سؤال‌های سخت‌تر، وقت بیشتر، یک راهنما |
| رکورد | رکورد شخصی؛ تکرار با واریانت‌های تازه |
| نبرد غول‌ها | ۷ غول (یک فصل = یک غول)، ۳ فاز، ۳ جان |
| مسیر تمرین | نقشهٔ فصل‌به‌فصل: مفهوم ← تمرین ← سرعت ← تسلط ← غول |
| **بهتر شو در ۱۵** | تشخیص ← تمرین هدفمند ← چالش زمانی ← مرور اشتباه ← آزمون مجدد ← گزارش قبل/بعد واقعی |
| دعوت دوستانه / دو نفره محلی | چالش زنده یا رد-و-بدل نوبتی |

## تست‌ها

```bash
bash scripts/run_tests.sh
```
پوشش: اعتبارسنجی ریاضی بانک سؤال، دو کلاینت مستقل برای دوئل کامل آنلاین، جام‌ها، واحد‌ها، E2E آفلاین مرورگری (شامل ری‌استارت و ماندگاری)، E2E آنلاین دو مرورگر، و QA بصری همهٔ صفحه‌ها. گزارش کامل: [docs/TEST_REPORT.md](docs/TEST_REPORT.md)

## ساخت APK

```bash
bash scripts/build_apk.sh     # aapt2 + javac + d8 + zipalign + apksigner (بدون نیاز به Gradle)
bash scripts/verify_apk.sh    # امضا، متادیتا، محتوا، sha256
```
وابستگی‌ها: JDK 17، build-tools 34، platform android-34 (مسیر پیش‌فرض `~/.deps`؛ با `ANDROID_DEPS` قابل تغییر).

## ساختار مخزن

```
app/       بازی HTML5 (JS خالص، RTL، بدون فریم‌ورک)
android/   شل WebView جاوا + مانیفست + آیکون‌ها + release.keystore
server/    بک‌اند Node.js (کد + تست + Docker + Prisma)
content/   خط تولید محتوا و خروجی‌ها (بانک سؤال، برنامه درسی، گزارش‌ها)
scripts/   build/verify/run_tests/watchdog/cron/export + تست‌های E2E
docs/      مستندات (استقرار، cron، متغیرها، گزارش تست/QA، محدودیت‌ها)
release/   خروجی نهایی (APK + اسکرین‌شات‌های QA)
```

## مجوز و منابع

- محتوای درسی از کتاب ریاضی (۱) پایه دهم (سازمان پژوهش و برنامه‌ریزی آموزشی) به‌عنوان **مبنای مفهومی** استفاده شده؛ سؤال‌ها واریانت‌های اصلی و تولید پارامتری هستند، نه رونوشتی از تمرین‌های کتاب.
- صداها به‌صورت سینتی‌ز Deer دیجیتال (WebAudio) تولید می‌شوند؛ هیچ صدای دارای کپی‌رایتی استفاده نشده.
- شخصیت‌ها، ماسکات «جبرو»، غول‌ها و آیکون‌ها اسامی/SVG اصلی این پروژه‌اند.
