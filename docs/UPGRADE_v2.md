# MATH ARENA v2.0.0 — Technical Summary

خلاصهٔ فنی ارتقای بزرگ (Directive B): موتور سؤال هوشمند، اتصال کتاب درسی، تختهٔ خط‌کشی و بازطراحی رابط.

---

## ۱. موتور سؤال هوشمند

**بانک v2**: ۷۳۲ سؤال از ۳۸ مهارت × ۷ فصل کتاب، در ۸ خانواده:

| خانواده | تعداد | مثال ساخت |
| --- | --- | --- |
| مستقیم ( تمرین پایه ) | ۲۷۷ | محاسبه، عضویت، معادله |
| کاربردی | ۹۶ | نظرسنجی شمول‌وعدم‌شمول، استهلاک، صندلی سالن، گردونه |
| مفهومی | ۷۸ | تعریف تابع، علامت ربع‌ها، جامعه/نمونه |
| وارونه | ۷۳ | «جملهٔ چندم؟»، «k چند است که دامنه [۴,∞) شود؟»، C(n,۲)=۱۵ |
| خطایاب | ۶۸ | «اولین گام غلط کدام است؟» — زنجیرهٔ ۴ گامی دانش‌آموز با خطای رایج واقعی |
| قضاوت | ۵۸ | همیشه/گاهی/هرگز با شاهد مثبت/مثال‌نقض |
| چندمرحله‌ای | ۵۷ | ترکیب توابع، sin→cos→tan، جدول علامت |
| چالشی ( خبره ) | ۲۵ | ویتا، رأس سهمی از دو شرط، sin در ربع دوم |

- **سختی = عمق استدلال، نه بزرگی اعداد**: ۴ سطح ( آسان/متوسط/سخت/خبره ) با زمان تخمینی ۲۲/۳۸/۶۰/۸۵ ثانیه و وزن تسلط ۰/۸ تا ۱/۶.
- **ضدحفظ‌کردن**: هر مولد ۲–۴ قالب ساختاری متفاوت دارد؛ اثرانگشت ساختاری ( sha1 متن با ارقام حذف‌شده ) تکرار هم‌ساخت را در هر مهارت به ۳ محدود می‌کند؛ چرخش خانواده در انتخاب ( سؤال پشت‌سرهم از یک خانوازه نمی‌آید وقتی جایگزین هست )؛ محل گزینهٔ درست در هر ۴ جایگاه می‌نشیند.
- **اعتبارسنجی مستقل** ( `content/pipeline/validators3.py` ): بازحل با روش متفاوت از مولد — شمارش کامل فضای حالت ( تاس ۳۶ حالت،committee با itertools )، تکرار به‌جای فرمول بسته ( دنباله‌ها، توان گویا )، نمونه‌گیری نقطه‌ای ( نامعادله، سهمی، قوس دروازه )، بازمشتق شاهدها ( جمع/ضرب گنگ‌ها از تجزیهٔ مربع‌کامل، تعداد ریشهٔ زوج/فرد )، سازگاری «اولین گام غلط» برای خطایاب.
- **بازخورد اختصاصی هر گزینهٔ غلط** ( `optionFeedback` ): «کسر را وارونه کرده‌ای»، «به‌جای (n−۱) پرش، n تا زده‌ای»، «علامت k را برعکس گرفته‌ای» — پاسخ غلط دیگر فقط «غلط» نیست؛ خطای ریاضی‌اش توضیح داده می‌شود و در تحلیل، الگوی اشتباه از همین متن‌ها طبقه‌بندی می‌شود ( علامت/فرمول/مرحلهٔ جاافتاده/محاسبه ).
- انتخاب تطبیقی: در حالت‌های تمرینی، مهارت‌های با تسلط ۵ دیگر پرسیده نمی‌شوند ( تا جایگزین کافی باشد )؛ هدف‌گیری سطح از عملکرد اخیر.

## ۲. اتصال کتاب درسی ( Traceability )

- نگاشت **صفحهٔ چاپی ↔ ایندکس فیزیکی PDF** با آفست ۵ ( pdf_index = book_page + ۵ )، صحت‌سنجی‌شده با فهرست مطالب و کلیدواژه‌های متن هر ۲۳ درس.
- هر سؤال: `sourcePages` ( بازهٔ درس ) + `bookPage` ( صفحهٔ اصلی مرجع ).
- **نشان مرجع روی هر سؤال**: `فصل ۲ · دایرهٔ مثلثاتی · صفحهٔ ۴۰` + دکمهٔ **«مشاهده در کتاب»**.
- نمایشگر کتاب: ۱۷۶ صفحهٔ رندرشده از PDF واقعی ( 100dpi JPEG، روی هم ۱۱MB داخل APK )، سرصفحه با مشخصات کتاب، صفحه‌گردانی، شمارهٔ صفحهٔ چاپی، زوم ۱۸۰٪، و **«بازگشت به بازی»** که اورلی را می‌بندد و مسابقه دقیقاً همان‌جایی که بود ادامه می‌یابد ( چون ناوبری صفحه عوض نمی‌شود ).
- مسیرها در بافت `file:///android_asset` هم تست شد ( بوت از APK استخراج‌شده ).

## ۳. تختهٔ خط‌کشی ( Whiteboard )

- ماژول `app/assets/js/whiteboard.js` ( ~۳۶۰ خط، بدون وابستگی ):
  - دستهٔ شناور جمع‌وجور → گسترش به اورلی ~۹۲٪ صفحه.
  - رسم انگشتی با Pointer Events + رویدادهای ادغام‌شده + هموارسازی درجه‌۲ نقطهٔ میانی؛ DPR با سقف ۲.
  - **۳ رنگ / ۳ ضخامت / پاک‌کن خط‌محور / شبکهٔ زمینه / واگرد و بازانجام چندسطحی ( پشتهٔ معکوس ) / پاک‌کردن همه / بستن**.
  - پاک‌کن با حذف کل خط‌هایی که در شعاع پاک‌کن قرار می‌گیرند — تا واگردپذیر بماند.
  - **ماندگاری**: Map درون‌حافظه به‌ازای سؤال + localStorage ( سقف ۱۲ سؤال اخیر، ۴۰ خط بر سؤال )؛ GC هنگام خروج از مسابقه.
  - رسم هیچ‌وقت پاسخ انتخاب نمی‌کند: اورلی صاحب رویدادهاست؛ دسته در نوار پایین جدا از گزینه‌هاست.
  - دکمهٔ خاموش/روشن در تنظیمات.

## ۴. رابط نیوی رقابتی ( بازطراحی کامل )

- پالت: `#071426 / #0B1D33 / #102A46 / #163956 / #38BDF8 / #D7E5F2 / #F2B84B` (+ معنایی: سبز/قرمز/بنفش/نعنایی).
- زبان فرم: پنل‌های تقریباً مستطیلی ( شعاع ۳–۵px )، خطوط ۱px، جداکننده‌های ساختاری، بدون سایه‌چسب، بدون دکمهٔ حبابی، بدون تصویرسازی کارتونی.
- تایپوگرافی: Vazirmatn با سلسله‌مراتب قوی ( display ۲۶/۹۰۰ → body ۱۵ → micro ۱۰/۵ با tracking ).
- لحن رقابتی: نوار پیشرفت جلسه، گیج ۴خکهٔ سطح سختی، برچسب خانوادهٔ سؤال، کمبو، حلقهٔ تایمر فازدار، رادار/مسیر پیشرفت.
- **سلسله‌مراتب صفحهٔ سؤال** ( پیاده‌سازی مشترک در `buildQuestionScene` برای دوئل/تک‌نفره/غول ):
  1. پیشرفت جلسه ( «سؤال ۲ از ۳» + track )
  2. موضوع + **نشان مرجع کتاب** ( مشاهده در کتاب )
  3. سطح سختی + خانواده
  4. صورت مسئله ( کانون، تایپ ریاضی LTR-ایزوله در متن RTL )
  5. گزینه‌ها ( لمس‌پذیر، متمایز؛ قضاوت‌ها تمام‌عرض )
  6. تخته ( دسته شناور )
  7. ناوبری/کمک‌ها ( حذف دو گزینه، زمان فکر، سرنخ )
- مسکوت ( mascot کارتونی ) با **نشان هندسی** ( شش‌ضلعی + گلیف ریاضی، حالت = رنگ/درخشش ) جایگزین شد؛ آواتارها نشانهٔ هندسی شدند ( id رنگ حفظ شد ).
- بازخورد پاسخ غلط: نوار رأی + **«خطای انتخاب تو»** ( از optionFeedback ) + راه‌حل + مفهوم + مراقب‌باش.

## ۵. تحلیل آموزشی

- ثبت هر پاسخ در `bySkill / byChapter / byDifficulty (1-4) / byFamily / byMistakeType`.
- صفحهٔ آمار: جدول عملکرد به تفکیک مفهوم ( دقت/تعداد/تسلط/سررسید مرور )، دقت به تفکیک سطح سختی، دقت به تفکیک نوع سؤال، **الگوی اشتباه‌های تکرارشونده** ( طبقه‌بندی از متن بازخورد گزینه‌ها، نه حدس )، و توصیهٔ تمرین با دکمهٔ پرش به فصل + فهرست مفاهیم مسلط که از تمرین تکراری کنار گذاشته شده‌اند.
- دفتر اشتباهات: نوع الگو + خانواده + سطح + «خطای انتخاب تو» روی هر کارت.

## ۶. سازگاری و مهاجرت

- کلید localStorage همان `matharena.v1` است؛ ادغام عمیق پیش‌فرض‌ها در `load()` آمار جدید را به state قدیمی اضافه می‌کند ( تست واقعی با state v1 انجام و باگش رفع شد ) + خودترمیمی در `recordAnswer`.
- سرور: `publicQuestion` و سریال‌سازی جام‌ها فیلدهای v2 را می‌برند؛ امتیازدهی تا سطح ۴؛ ترکیب سؤال مرحله با تنوع خانواده.
- فایل‌های جدید: `whiteboard.js`، `bookviewer.js`، `assets/book/p-*.jpg` ( ۱۷۶ )، `book_index.js/json`؛ تغییر یافته‌های اصلی: `core.js`، `data.js`، `game.js`، `screens-game.js`، `screens-learn.js`، `ui.js`، `main.css` ( بازنویسی کامل )، `index.html`، سرور `content.js/duel.js/tournaments.js`.
